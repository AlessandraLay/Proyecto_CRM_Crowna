# Crowna CRM

Crowna CRM es una plataforma de gestión de relaciones con clientes diseñada para ayudar a las empresas a organizar, automatizar y mejorar la gestión de sus clientes.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Git
- GitHub
- GitHub Pages
